# Bili-Bili Bistro

A modern restaurant website built with JavaScript modules, Webpack, HTML, and CSS.

## Features

- Responsive restaurant homepage
- Menu page with categorized dishes
- Contact and reservation form
- Professional footer with social links
- Optimized image assets
- GitHub Pages deployment through the `docs/` folder

## Tech Stack

- HTML
- CSS
- JavaScript ES modules
- Webpack

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run start
```

Build the production site:

```bash
npm run build
```

The production build is generated in the `docs/` folder.

## GitHub Pages Deployment

This project is configured for GitHub Pages using the `docs/` folder.

After making changes, run:

```bash
npm run build
```

Then commit and push the updated files:

```bash
git add .
git commit -m "Update restaurant website"
git push
```

In GitHub, go to:

`Settings` -> `Pages`

Set:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

The site will be available at:

https://busiswabilibili.github.io/bili-bili-bistro/
